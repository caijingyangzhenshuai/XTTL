## 四、各模型核心内容要点（设计数据）

**YOLOv4**：DVPP硬件JPEG解码+缩放 → NV12 → 推理 → NMS(10647候选框, IoU=0.8) → 80类COCO
**YOLOv3**：CPU预处理(RGB→NV12) + image_info双输入 → 推理 → NMS → 80类COCO
**VGG-SSD**：AIPP/CPU预处理自动探测 → 推理 → 双输出(坐标+置信度) → NMS → 20类VOC
**RT-DETR**：FP32预处理(640×640) + target_sizes双输入 → 推理 → labels/boxes/scores三输出 → NMS → 80类COCO
**ResNet50**：ImageNet归一化(224×224, NCHW) → 推理 → Top-5
**MobileNetV1**：轻量级深度可分离卷积(224×224, CHW) → 推理 → Top-5
**VGG16**：动态尺寸解析(NV12) → 推理 → OOD过滤(Top1<60% 或 差距>98%)
**DeepLabV3**：513×513 int8 RGB → 推理 → 像素统计 + 彩色可视化分割图
**LLMClient**：HTTP封装(cpr/curl) + 重试(3次) + JSON解析 + 重复内容检测 + Top-K采样
**命令行接口**：argparse + --modelfile/--imagefile/--prompt + --help + 结果格式化输出
