======================================================================
        模型转换帮助（Model Conversion Guide）
        适用平台：Ascend 310P3 与 Ascend 910B4
======================================================================

【重要前提】
1. .om 文件与芯片型号相关，**不可跨芯片复用**。
   - 某个 soc 转换出的 .om 只能在同 soc 上加载。
   - 换芯片必须用对应 --soc_version 重新转换。
2. **910 系列不支持 Caffe（--framework=0）格式的模型转换**。
   - 只有 ONNX（--framework=5）和 TensorFlow pb（--framework=3）可以在 910 上转换。
   - Caffe 源模型只能在 310P3 上转换。
3. 转换前先激活环境：
     source /usr/local/Ascend/ascend-toolkit/set_env.sh
   （确认芯片型号可用：npu-smi info）

----------------------------------------------------------------------
【框架参数对应关系】
  --framework=0 : Caffe        【310 支持 / 910 不支持】
  --framework=3 : TensorFlow (pb)   【310 支持 / 910 支持】
  --framework=5 : ONNX         【310 支持 / 910 支持】

  --soc_version :
     Ascend310P3 -> 310P 系列机器
     Ascend910B4 -> 910B 系列机器（800I 常为 910B4）

======================================================================
一、YOLOv4（源：TensorFlow pb）
======================================================================
输入: Input:1,416,416,3（NHWC, 用 AIPP 插桩）

310P3:
atc --input_shape="Input:1,416,416,3" --output=./yolov4 \
    --insert_op_conf=./insert_op_yolov4.cfg --framework=3 \
    --model=./yolov4_no_postprocess.pb --soc_version=Ascend310P3

910B4（pb 支持，但需重新转换）:
atc --input_shape="Input:1,416,416,3" --output=./yolov4 \
    --insert_op_conf=./insert_op_yolov4.cfg --framework=3 \
    --model=./yolov4_no_postprocess.pb --soc_version=Ascend910B4

精度切换（末尾加 --output_type=FP16 或 =INT8）:
  FP16:  ... --output=./yolov4 --output_type=FP16 ...
  INT8:  ... --output=./yolov4 --output_type=INT8 ...

======================================================================
二、ResNet50（源：ONNX）
======================================================================
输入: input.1:1,3,224,224（NCHW）

910B4:
atc --model=./resnet50.onnx --framework=5 --output=resnet50 \
    --soc_version=Ascend910B4 --input_shape="input.1:1,3,224,224"

310P3（如需在 310 上跑, 仅改 soc）:
atc --model=./resnet50.onnx --framework=5 --output=resnet50 \
    --soc_version=Ascend310P3 --input_shape="input.1:1,3,224,224"

精度切换（末尾加 --output_type=FP16 或 =INT8）:
  FP16:  ... --output=resnet50_fp16 --output_type=FP16 ...
  INT8:  ... --output=resnet50_int8 --output_type=INT8 ...

======================================================================
三、VGG16（源：TensorFlow pb，猫狗分类）
======================================================================
输入: input_1:1,224,224,3（NHWC, AIPP）

310P3:
atc --output_type=FP32 --input_shape="input_1:1,224,224,3" \
    --input_format=NHWC --output="vgg16_cat_dog" \
    --soc_version=Ascend310P3 --insert_op_conf=insert_op_vgg16.cfg \
    --framework=3 --model="./vgg16_cat_dog.pb"

910B4（pb 支持，仅改 soc 重新转换）:
atc --output_type=FP32 --input_shape="input_1:1,224,224,3" \
    --input_format=NHWC --output="vgg16_cat_dog" \
    --soc_version=Ascend910B4 --insert_op_conf=insert_op_vgg16.cfg \
    --framework=3 --model="./vgg16_cat_dog.pb"

精度切换（改 --output_type=FP16，AIPP 限制不推荐 INT8）:
  FP16:  ... --output_type=FP16 ...

======================================================================
四、YOLOv3（caffe 版，产物 yolov3_yuv.om）——【910 不支持】
======================================================================
输入: YUV NV12 416x416（用 AIPP 插桩）
注意: Caffe 模型无法在 910 上转换！只能用于 310P3。
推理时对应代码：yolov3_yuv.py / yolov3_yuv.{h,cpp}，类名 YOLOv3YUV/YOLOv3YUVDetect。

310P3（仅在 310 可用）:
atc --model=yolov3.prototxt --weight=yolov3.caffemodel \
    --framework=0 --output=yolov3_yuv \
    --soc_version=Ascend310P3 --insert_op_conf=aipp_nv12.cfg

（若要在 910 上跑 YOLOv3，需改用 ONNX 源模型，
  见文末"YOLOv3 ONNX 版"。）

======================================================================
五、DeepLabV3（源：TensorFlow pb，语义分割）
======================================================================
输入: ImageTensor:1,513,513,3

310P3:
atc --model=./deeplabv3_plus.pb --framework=3 \
    --output=deeplabv3_plus --soc_version=Ascend310P3 \
    --input_shape="ImageTensor:1,513,513,3" \
    --output_type="SemanticPredictions:0:FP32" \
    --out_nodes="SemanticPredictions:0"
(如果失败，尝试增加交换内存)

910B4（pb 支持，仅改 soc 重新转换）:
atc --model=./deeplabv3_plus.pb --framework=3 \
    --output=deeplabv3_plus --soc_version=Ascend910B4 \
    --input_shape="ImageTensor:1,513,513,3" \
    --output_type="SemanticPredictions:0:FP32" \
    --out_nodes="SemanticPredictions:0"

精度切换（改 --output_type 内的 FP32 为 FP16 或 INT8）:
  FP16:  ... --output_type="SemanticPredictions:0:FP16" ...
  INT8:  ... --output_type="SemanticPredictions:0:INT8" ...

======================================================================
六、MobileNetV1（源：ONNX，支持三精度切换）
======================================================================
输入: image:1,3,224,224（NCHW）

FP32（默认）:
python3 mobilenet-v1_pth2onnx.py mobilenet_sgd_rmsprop_69.526.tar mobilenet-v1.onnx
atc --framework=5 --model=./mobilenet-v1.onnx \
    --input_format=NCHW --input_shape="image:1,3,224,224" \
    --output=mobilenet-v1_fp32 --soc_version=Ascend910B4

FP16:
atc --framework=5 --model=./mobilenet-v1.onnx \
    --input_format=NCHW --input_shape="image:1,3,224,224" \
    --output=mobilenet-v1_fp16 --soc_version=Ascend910B4 \
    --output_type=FP16

INT8:
atc --framework=5 --model=./mobilenet-v1.onnx \
    --input_format=NCHW --input_shape="image:1,3,224,224" \
    --output=mobilenet-v1_int8 --soc_version=Ascend910B4 \
    --output_type=INT8

310P3（仅改 soc）:
  FP32:  ... --soc_version=Ascend310P4
  FP16:  ... --output=mobilenet-v1_fp16 --output_type=FP16 --soc_version=Ascend310P3
  INT8:  ... --output=mobilenet-v1_int8 --output_type=INT8 --soc_version=Ascend310P3

======================================================================
七、VGG-SSD（源：Caffe）——【910 不支持】
======================================================================
输入: data:1,3,300,300（NCHW, AIPP）
注意: Caffe 模型无法在 910 上转换！只能用于 310P3。

310P3（仅在 310 可用）:
atc --output_type=FP32 --input_shape="data:1,3,300,300" \
    --weight=./vgg_ssd.caffemodel --input_format=NCHW \
    --output=./vgg_ssd --soc_version=Ascend310P3 \
    --insert_op_conf=./insert_op_ssd.cfg --framework=0 \
    --save_original_model=false --model=./vgg_ssd.prototxt

精度切换（改 --output_type=FP16，AIPP 限制不推荐 INT8）:
  FP16:  ... --output_type=FP16 ...

======================================================================
八、SSD（ssd-10.onnx，源：ONNX）
======================================================================
输入: image:1,3,1200,1200（NCHW, RGB /255）
输出: bboxes / labels / scores（模型自带 NMS，可直接转换）

310P3:
atc --model=./ssd-10.onnx --framework=5 \
    --input_shape="image:1,3,1200,1200" \
    --input_format=NCHW --output_type=FP32 \
    --output=./ssd-10 --soc_version=Ascend310P3 --log=debug

910B4:
atc --model=./ssd-10.onnx --framework=5 \
    --input_shape="image:1,3,1200,1200" \
    --input_format=NCHW --output_type=FP32 \
    --output=./ssd-10 --soc_version=Ascend910B4 --log=debug

精度切换（末尾加 --output_type=FP16 或 =INT8）:
  FP16:  ... --output_type=FP16 ...
  INT8:  ... --output_type=INT8 ...

======================================================================
九、YOLOv3 ONNX 版（yolov3-10.onnx → 裁剪版）
======================================================================
说明: 原 yolov3-10.onnx 自带 NMS 后处理（含 CANN 不支持的 Loop 算子），
      ATC 无法直接转换。需先裁剪掉后处理，只保留主干，再转换。

第1步 裁剪（需在装有 onnx 的 python 环境执行）:
python3 << 'PYEOF'
import onnx
from onnx import utils
utils.extract_model(
    input_path='./yolov3-10.onnx',
    output_path='./yolov3_backbone.onnx',
    input_names=['input_1', 'image_shape'],
    output_names=['convolution_output2', 'convolution_output1', 'convolution_output']
)
print('done')
PYEOF

第2步 转换:
310P3:
atc --model=./yolov3_backbone.onnx --framework=5 \
    --input_shape="input_1:1,3,416,416;image_shape:1,2" \
    --input_format=NCHW --output_type=FP32 \
    --output=./yolov3_backbone --soc_version=Ascend310P3 --log=debug

910B4:
atc --model=./yolov3_backbone.onnx --framework=5 \
    --input_shape="input_1:1,3,416,416;image_shape:1,2" \
    --input_format=NCHW --output_type=FP32 \
    --output=./yolov3_backbone --soc_version=Ascend910B4 --log=debug

精度切换（末尾加 --output_type=FP16 或 =INT8）:
  FP16:  ... --output_type=FP16 ...
  INT8:  ... --output_type=INT8 ...

======================================================================
	【推理精度控制】
	----------------------------------------------------------------------
	推理框架支持三种精度：
	  FP32: 全程 32bit 计算，精度最高
	  FP16: 半精度计算，性能≈2×，精度几乎无损
	  INT8: 定点量化，需校准集，性能最高
	----------------------------------------------------------------------
	【--output_type 参数说明】
	  --output_type 控制模型输出的数据类型，C++/Python 推理代码已自动适配。
	
	  推荐组合：
	    FP32:  --precision=fp32 --output_type=FP32
	    FP16:  --precision=fp16 --output_type=FP16
	    INT8:  --precision=fp16 --output_type=INT8
	
	  注：--output_type 只影响输出，不影响输入。输入仍为 FP32。
	  各模型缺省 --output_type 时默认输出 FP32。
	----------------------------------------------------------------------
	【MobileNetV1 三精度转换示例】
	----------------------------------------------------------------------
	FP32:
	atc --framework=5 --model=./mobilenet-v1.onnx \
	    --input_format=NCHW --input_shape="image:1,3,224,224" \
	    --output=mobilenet-v1_fp32 --soc_version=Ascend910B4
	
	FP16:
	atc --framework=5 --model=./mobilenet-v1.onnx \
	    --input_format=NCHW --input_shape="image:1,3,224,224" \
	    --output=mobilenet-v1_fp16 --soc_version=Ascend910B4 \
	    --output_type=FP16
	
	INT8:
	atc --framework=5 --model=./mobilenet-v1.onnx \
	    --input_format=NCHW --input_shape="image:1,3,224,224" \
	    --output=mobilenet-v1_int8 --soc_version=Ascend910B4 \
	    --output_type=INT8
	----------------------------------------------------------------------
	其他模型如需切换精度，在对应 ATC 命令末尾加 --output_type=FP16 或 =INT8 即可。
	（Caffe 模型注：910 不支持，仅 310P3 可转）
	----------------------------------------------------------------------
【速查表】
		----------------------------------------------------------------------
		模型          | 源格式 | 310P3 | 910B4 | 备注
		--------------|--------|-------|-------|------------------------------
		YOLOv4        | pb     |  ✓   |  ✓   | NHWC+AIPP
		ResNet50      | onnx   |  ✓   |  ✓   | NCHW
		VGG16         | pb     |  ✓   |  ✓   | NHWC+AIPP
		YOLOv3_yuv(caffe)| caffe   |  ✓   |  ✗   | 910 不支持 caffe, NV12+AIPP
		DeepLabV3+    | pb     |  ✓   |  ✓   |
		MobileNetV1   | onnx   |  ✓   |  ✓   | NCHW
		VGG-SSD(caffe)| caffe  |  ✓   |  ✗   | 910 不支持 caffe
		SSD-10        | onnx   |  ✓   |  ✓   | NCHW, 自带NMS
		YOLOv3-10     | onnx   |  ✓   |  ✓   | 先裁剪再转换
		----------------------------------------------------------------------
		✗ = 910 不支持 Caffe 格式转换，此类模型只能在 310P3 上跑。
